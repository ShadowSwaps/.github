# ShadowSwaps community defaults

This public repository supplies the default [Ko-fi support link](https://ko-fi.com/shadowswaps) for repositories owned by ShadowSwaps.

GitHub inherits the .github/FUNDING.yml file when a repository has no funding file of its own. Repository-specific funding files take precedence.

Support is optional. This configuration starts no donation, subscription, workflow or paid service.

See [GitHub community-file documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for inheritance behavior.
